### 1.3 术语

| 术语 | 定义 |
| --- | --- |
| 任务 | 用户要完成的一件事，属于某个清单，可有子任务、到期时间、提醒和重复规则 |
| 清单 | 任务的集合；收件箱是系统默认清单 |
| 今天 | 用户当前时区下，今天到期、已逾期、今天完成三类任务的聚合视图 |
| 智能视图 | 系统内置的筛选视图：今天、即将到来、全部、已完成、回收站 |
| 实例 | 重复任务在当前到期时间对应的一次发生；完成实例后推进到下一次 |
| occurrenceKey | 实例标识；全天为 `date:YYYY-MM-DD`，定时为 `at:<ISO8601 UTC>` |
| Outbox | 客户端本地待同步操作队列；与业务写入同事务提交 |
| 同步游标 | 客户端已应用的最后一个服务端 `seq`；只由 `/sync/pull` 推进 |
| 冲突 | 同一字段在多个设备上并发修改；MVP 保留服务端版本并提示用户 |
| 墓碑 | 软删除记录；用于把删除传播到其他设备，30 天后物理清理 |

## 2. 产品概述

### 2.1 一句话定位

**一个快、稳、离线可用的个人待办应用。**

### 2.2 目标

- 用户能在 3 秒内记录一件事，不打断当前工作；
- 打开 App 就能看到“今天要做什么”，不需要复杂配置；
- 地铁、飞机、弱网下可正常使用，联网后自动同步；
- 多设备最终一致，已确认的写入不丢失；
- 用户能导出、能注销、能彻底删除自己的数据；
- 1–3 人团队可在 15–16 周内交付 MVP。

### 2.3 非目标（MVP 明确不做）

- 多人共享清单、评论、@提及、实时协作；
- 甘特图、看板、番茄钟、时间块；
- 日历双向同步、邮件转发建任务；
- 微信小程序、桌面原生、Apple Watch；
- 开放 API、插件、自动化规则；
- 广告、社交关系链、内容推荐。

### 2.4 目标用户与场景

| 用户群 | 场景 | 核心诉求 |
| --- | --- | --- |
| 学生 | 作业、复习、社团事务 | 截止提醒、重复任务、按清单整理 |
| 职场个人 | 会议待办、临时想法、私人事务 | 快速记录、今天视图、跨端同步 |
| 自由职业者 | 多客户交付、跟进、发票 | 多清单、标签、搜索 |
| 轻度用户 | 购物、家务、旅行准备 | 简单、不打扰、不用学习 |

### 2.5 成功指标

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 激活率 | ≥ 60% | 首次启动 24 小时内创建第一个任务 |
| 次日留存 | ≥ 35% | 次日再次打开 |
| 7 日留存 | ≥ 20% | 第 7 日再次打开 |
| 周完成任务数 | ≥ 8 | 活跃用户中位数 |
| 同步成功率 | ≥ 99.5% | 非冲突 push 成功比例 |
| 崩溃率 | < 0.5% | 无崩溃会话占比 |
| 提醒延迟 | P95 ≤ 5 分钟 | 从计划时间到推送发出 |
| 商店评分 | ≥ 4.5 | 上线 30 天后 |

指标仅用于产品改进，采集匿名事件，不采集任务内容。

## 3. 信息架构与导航

### 3.1 一级导航

底部 4 个 Tab：

1. **今天**：默认首页；
2. **清单**：收件箱、自定义清单、系统视图；
3. **搜索**：即时搜索与过滤；
4. **设置**：账户、外观、通知、数据、关于。

### 3.2 页面清单

| 页面 | 层级 | 入口 | 关键内容 |
| --- | --- | --- | --- |
| 启动/引导 | 全屏 | 首次启动 | 价值主张、登录、通知权限 |
| 登录 | 全屏 | 引导/设置 | 邮箱验证码、Apple、Google |
| 今天 | Tab 1 | 启动 | 日期、同步状态、逾期/今天/已完成分组 |
| 清单 | Tab 2 | 底部导航 | 收件箱、自定义清单、智能视图 |
| 清单详情 | 二级 | 清单列表 | 任务分组、批量操作、清单菜单 |
| 任务详情 | 全屏 | 任务行/通知 | 标题、备注、日期、提醒、重复、优先级、子任务 |
| 搜索 | Tab 3 | 底部导航 | 搜索框、最近搜索、结果、筛选 |
| 设置 | Tab 4 | 底部导航 | 账户、外观、行为、通知、数据、关于 |
| 回收站 | 二级 | 设置/清单 | 已删除任务、恢复、彻底删除 |
| 同步冲突 | 二级/提示 | 任务标记/同步状态 | 冲突字段、采用服务端版本、重新编辑 |
| 通知中心（P1） | 二级 | 提醒/设置 | 最近提醒、跳转任务 |

### 3.3 导航规则

- 任务详情使用全屏模态，关闭后回到来源页面并保持滚动位置；
- 通知深链：任务存在 → 任务详情；已删除 → 今天视图并提示；无权限 → 登录；
- 清单详情不提供多级抽屉，避免层级过深；
- 返回手势与 Android 返回键行为一致；
- 未保存的编辑在返回时提示“放弃修改？”（P1 自动保存草稿）。

## 4. 角色与权限

### 4.1 MVP

仅个人用户一种角色：

- 只能访问自己的数据；
- 所有读写按 `userId` 隔离；
- 设备可被同一用户移除；
- 无管理员后台面向最终用户。

### 4.2 V2 协作预留

| 角色 | 权限 |
| --- | --- |
| Owner | 管理清单、邀请/移除成员、删除清单 |
| Editor | 创建/编辑/完成任务，不可管理成员 |
| Viewer | 只读 |

协作上线前必须补齐 ACL、邀请、成员管理、实时更新与 UGC 举报/屏蔽。

## 5. 核心业务流程

### 5.1 首次使用

1. 启动 → 价值主张（3 屏以内，可跳过）；
2. 登录（邮箱验证码 / Apple / Google）；
3. 自动创建收件箱，读取系统时区与语言；
4. 请求通知权限（可跳过，设置中可再开启）；
5. 引导创建第一个任务，或进入今天空状态。

异常：

- 验证码错误/过期：就地提示，可重发；
- 网络不可用：登录不可离线完成，提示检查网络；已登录用户可离线使用；
- 通知权限拒绝：不阻塞，任务编辑页展示一次非阻塞提示。

### 5.2 快速记录

1. 今天/清单详情点击“+ 新任务”；
2. 输入标题，回车或点击“保存”；
3. 任务立即出现在列表顶部；
4. 本地写入 + outbox 同事务提交；
5. 回到前台/网络恢复时自动同步。

要求：

- 只填标题即可保存；
- 不强制选择清单/日期/优先级；
- 支持中文输入法组合态，不误提交；
- 保存后焦点回到新增入口，支持连续记录。

### 5.3 今日安排

1. 打开今天；
2. 顶部显示日期、星期、同步状态；
3. 分组：已逾期、今天、今天已完成（默认折叠）；
4. 点击复选框完成任务；左滑删除/延期（P1 可配置）；
5. 点击任务行进入详情；
6. 下拉同步；无网络时显示离线状态。

### 5.4 任务生命周期

```text
创建 → 未完成（可编辑/安排/提醒）
   ├─ 完成（一次性）→ 已完成（可撤销 5 秒）→ 90 天内可查看 → 可在设置清除
   ├─ 完成（重复）→ 推进下一次实例 → 保持未完成
   ├─ 删除 → 回收站 30 天 → 恢复 / 彻底删除
   └─ 所属清单删除 → 移动到收件箱 / 随清单删除
```

### 5.5 离线与同步

1. 用户操作先写本地 SQLite 与 outbox；
2. UI 立即更新；
3. 同步引擎在 500ms 防抖后上传；
4. 服务端 ack 后标记 outbox 完成；
5. 通过 `/sync/pull` 拉取其他设备变更；
6. 冲突字段保留服务端版本并在任务上标记；
7. 同步状态在标题栏/设置中可见。

### 5.6 搜索

1. 进入搜索 Tab；
2. 输入 ≥2 个字符（中文）或 ≥2 个字符（英文）后 200ms 防抖查询；
3. 本地 FTS5 / LIKE 返回结果；
4. 点击进入任务详情；
5. 无结果展示空状态与“清除筛选”；
6. 历史搜索仅本地保存，最多 10 条（P1）。

### 5.7 数据导出与注销

1. 设置 → 数据 → 导出；
2. 选择 JSON 或 CSV；
3. 服务端异步生成，客户端轮询/推送通知；
4. 下载链接 24 小时有效；
5. 注销账号：二次确认 + 输入“删除”确认 → 立即停用、撤销令牌 → 30 天内删除数据；
6. 注销前提示导出，注销后不可恢复。

## 6. 详细功能需求

### 6.1 FR-1 账户与设备

#### 6.1.1 登录方式

| 方式 | 规则 | 优先级 |
| --- | --- | --- |
| 邮箱验证码 | 6 位数字；5 分钟有效；最多 5 次尝试；同一邮箱 60 秒内不可重复发送，1 小时最多 10 次 | P0 |
| Sign in with Apple | 校验 identityToken；必须提供（因有第三方登录） | P0 |
| Google 登录 | 校验 idToken；海外 | P0 |
| 手机号验证码 | 中国大陆；短信服务商；规则同邮箱 | P1 |
| 微信登录 | 中国大陆；OpenSDK | P1 |

规则：

- 首次登录自动创建用户、收件箱和默认设置；
- 邮箱统一小写；已被注销的邮箱在数据清理后可重新注册；
- 同一邮箱/Apple/Google 身份只能绑定一个用户；
- 登录失败不泄露账号是否存在（统一“验证码已发送/登录失败”文案）。

#### 6.1.2 会话与令牌

| 项目 | 规则 |
| --- | --- |
| 访问令牌 | JWT，15 分钟；claims 含 `uid`、`did`、`authVersion`、`deviceAuthVersion` |
| 刷新令牌 | 不透明随机串，仅存哈希；30 天；每次刷新轮换 |
| 重放检测 | 旧刷新令牌被使用 → 撤销整个 family，要求重新登录 |
| 即时撤销 | 移除设备/注销账号 → 递增版本并清缓存；旧访问令牌下一次请求即拒绝 |
| 登录设备 | 同时最多 10 台；超出时提示移除旧设备 |
| 退出所有设备 | 撤销所有刷新令牌与访问令牌版本 |

#### 6.1.3 设备管理

- 展示设备名（系统名 + 可编辑备注）、平台、最近活跃时间；
- 可远程移除；移除后该设备刷新令牌立即失效，访问令牌下一次请求失效；
- 退出登录时注销当前设备推送 token；
- 客户端卸载后 token 由推送回执/失效清理任务回收。

#### 6.1.4 账户资料

- 昵称 1–50 字符；
- 头像：预置 12 个可选头像；上传 P1；
- 时区：系统自动识别，可手动搜索 IANA 时区；
- 语言：简体中文 / English；
- 修改时区触发未来提醒重算（见 FR-5）。

#### 6.1.5 注销与导出

| 项目 | 规则 |
| --- | --- |
| 注销入口 | 设置 → 账户 → 注销账号 |
| 确认 | 二次确认，输入“删除”后才能提交 |
| 生效 | 立即停用、撤销全部令牌、隐藏数据 |
| 物理删除 | 30 天内删除数据库记录、对象存储文件；备份按保留周期自然过期 |
| 导出 | JSON 全量 + CSV 任务表；异步任务；链接 24 小时有效 |
| 导出范围 | 用户、设置、清单、任务、标签、提醒、附件元数据；附件二进制单独打包（P1） |

#### 6.1.6 验收要点

- 无网络时已登录用户可正常使用 P0 功能；
- 刷新令牌重放会撤销整条会话链；
- 移除设备/注销后旧访问令牌下一次请求被拒绝；
- 注销 30 天后数据库中不存在该用户数据；
- 导出文件可被第三方工具解析。

### 6.2 FR-2 任务管理

#### 6.2.1 任务字段

| 字段 | 类型/规则 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | UUIDv7 | 是 | 客户端生成，离线可用 |
| title | 1–500 字符 | 是 | 去除首尾空白后校验 |
| notes | Markdown 子集，≤10,000 字符 | 否 | 支持加粗/斜体/列表/引用/链接/行内代码 |
| listId | 用户自有清单 | 是 | 默认收件箱 |
| parentId | 同用户同清单任务，深度 1 | 否 | 子任务不可再有子任务 |
| priority | 0–3 | 否 | 0 无、1 低、2 中、3 高 |
| dueDate | 本地日期 `YYYY-MM-DD` | 否 | 与 dueAt 互斥 |
| dueAt | UTC 时间戳 | 否 | 与 dueDate 互斥 |
| reminderSpec | `{id, offsetMinutes}[]`，≤5 | 否 | 需要 dueDate 或 dueAt |
| recurrence | RRULE 子集 + dtstart + timezone + until/count | 否 | 见 FR-6 |
| tagIds | UUID 数组，≤10 | 否 | P1 |
| sortRank | 字符串 | 是 | 分数索引，拖动排序 |
| completedAt | UTC 时间戳 | 否 | 一次性任务完成时间；重复系列结束时设置 |
| lastCompletedAt | UTC 时间戳 | 否 | 重复任务最近一次完成 |
| version | 服务端递增整数 | 是 | 并发控制 |
| deletedAt | UTC 时间戳 | 否 | 回收站 |

#### 6.2.2 创建与编辑

- 快速创建只要求标题；默认清单 = 当前清单或用户默认清单；
- 标题去除首尾空白后不可为空；超过 500 字符截断并提示；
- 编辑保存采用自动保存（P1）或显式保存（MVP）；
- 修改 `listId` 时保留子任务并一起移动；
- 修改到期时间会重算提醒；
- 编辑重复规则只影响当前及未来实例，不影响已完成历史；
- 并发编辑冲突按 FR-8 处理。

#### 6.2.3 完成与撤销

- 点击复选框完成；再次点击取消完成（仅一次性任务）；
- 完成后记录 `completedAt`，从默认列表隐藏；
- 重复任务完成**当前实例**：记录 `lastCompletedAt`，推进下一次到期，任务保持未完成；完成请求带 `occurrenceKey`，服务端台账幂等；
- 完成后 5 秒内可撤销：一次性任务清除 `completedAt`；重复任务按 `completionId` 恢复旧到期时间、计数、序号和上次完成时间；
- 超过 5 秒或已被后续完成覆盖，不提供撤销；
- 完成操作必须离线可用，恢复网络后同步。

#### 6.2.4 删除与回收站

- 删除既可从任务行左滑，也可在详情页；
- 删除进入回收站，保留 30 天；
- 回收站可恢复或彻底删除；彻底删除不可恢复；
- 30 天后清理任务自动物理删除；
- 删除/恢复同步到其他设备；删除任务时子任务一起删除；
- 删除清单时用户选择“移动到收件箱”或“连同任务删除”。

#### 6.2.5 排序

| 排序 | 规则 | 优先级 |
| --- | --- | --- |
| 手动（默认） | `sortRank` 分数索引；拖动插入 | P0 |
| 到期时间 | 有日期在前，按 dueAt/dueDate 升序 | P0 |
| 优先级 | 高→低，同优先级按到期 | P0 |
| 创建时间 | 新→旧 | P1 |
| 标题 | 拼音/字典序 | P2 |

- 排序偏好按清单记忆；默认手动；
- 手动排序冲突只影响位置，不影响数据。

#### 6.2.6 子任务

- 最多 1 层；
- 父任务展示 `已完成/总数`；
- 父任务可独立完成，不强制子任务完成；若有未完成子任务，完成父任务时提示“还有 N 个子任务未完成”，用户可确认；
- 删除父任务级联删除子任务；
- 移动父任务时子任务跟随。

#### 6.2.7 批量操作

- 批量完成/删除/移动，单次最多 100 条；
- 操作前提示影响数量；
- 批量删除进入回收站；
- 部分失败时逐条返回结果，不静默丢弃。

#### 6.2.8 验收要点

- 飞行模式下创建/编辑/完成/删除立即生效，重启后仍在；
- 连续点击完成不会产生重复完成记录；
- 删除后 5 秒撤销、30 天内回收站恢复均可用；
- 子任务移动后父任务计数正确；
- 两台设备并发编辑不同字段最终一致。

### 6.3 FR-3 清单与视图

#### 6.3.1 系统清单

| 清单 | 规则 |
| --- | --- |
| 收件箱 | 每个用户唯一、不可删除、默认清单；可归档？否 |
| 回收站 | 系统视图，不参与清单排序；30 天保留 |

#### 6.3.2 自定义清单

- 名称 1–50 字符，用户内不区分大小写唯一（未删除时）；
- 颜色 12 选 1，图标 24 选 1；
- 可归档；归档后不出现在主列表，任务仍可通过搜索/全部找到；
- 每个用户最多 500 个清单；
- 可拖动排序；
- 删除时选择任务去向（默认移动到收件箱）。

#### 6.3.3 智能视图

| 视图 | 定义 |
| --- | --- |
| 今天 | dueDate=今天 或 dueAt 落在今天，或已逾期未完成；包含今天完成折叠区 |
| 即将到来 | 未来 7 天内到期（不含今天） |
| 全部 | 所有未完成任务，可按清单过滤 |
| 已完成 | `completedAt` 非空，最近 90 天 |
| 回收站 | `deletedAt` 非空，最近 30 天 |

规则：

- “今天”边界按用户当前时区计算；前台跨午夜自动刷新；
- 修改时区后立即重算；
- 逾期任务在“今天”中显示为逾期分组；
- 已完成视图包含已结束的重复系列，但不展示历史实例明细（P2）。

#### 6.3.4 清单详情

- 分组：逾期 / 今天 / 之后 / 无日期（P1）；
- 顶部显示未完成计数；
- 支持排序切换、显示/隐藏已完成；
- 支持批量选择；
- 空状态提供“添加第一个任务”；
- 清单菜单：编辑、归档、删除、排序。

#### 6.3.5 验收要点

- 移动任务后两个清单计数正确；
- 删除清单时明确任务去向，不静默丢任务；
- 时区变化后今天视图正确；
- 500 个清单下滚动与计数性能达标。

### 6.4 FR-4 组织、筛选与搜索

#### 6.4.1 搜索

- 触发：输入 ≥2 个字符，200ms 防抖；
- 范围：未删除任务的标题与备注；回收站内单独搜索；
- 本地优先：SQLite FTS5 trigram（≥3 字）；2 字用 `LIKE` + 限制条数；FTS5 不可用时全部 `LIKE`；
- 结果按更新时间倒序，标题命中优先，关键词高亮；
- 点击结果进入任务详情，返回保留搜索词；
- 50,000 条任务下 P95 < 200ms；
- 服务端兜底用于 Web/本地缓存缺失，2 字查询走 `ILIKE` + `LIMIT`。

#### 6.4.2 标签（P1）

- 标签名 1–30 字符，用户内唯一；
- 颜色 12 选 1；
- 一个任务最多 10 个标签；
- 删除标签不删除任务，关联自动解除；
- 标签管理页支持重命名、改色、删除、查看任务数。

#### 6.4.3 筛选（P1）

- 维度：清单、状态、标签、优先级、到期范围；
- 组合关系 AND；
- 筛选条件可保存为自定义筛选（P2）；
- 筛选结果计数实时更新；
- 清除筛选一键恢复。

#### 6.4.4 排序与展示

- 列表支持到期/优先级/创建时间/标题排序；
- 升/降序；
- 排序偏好按视图记忆；
- 搜索结果固定按相关度/更新时间，不提供自定义排序。

#### 6.4.5 验收要点

- 中文 2 字/3 字搜索都能命中标题与备注；
- 50,000 条任务下 P95 < 200ms；
- 标签删除后任务保留；
- 筛选组合结果正确且可清除。

### 6.5 FR-5 时间与提醒

#### 6.5.1 日期语义

| 类型 | 存储 | 显示 | 提醒基准 |
| --- | --- | --- | --- |
| 全天 | `due_date`（本地日期） | “今天/明天/11月2日” | 当天 09:00 本地时间 + 偏移 |
| 定时 | `due_at`（UTC） | 用户时区时间 | 到期时间 + 偏移 |
| 无日期 | 两字段为空 | 不显示日期 | 不允许提醒 |

规则：

- 二者互斥，可都不填；
- 全天任务跨时区不漂移日期；
- 定时任务跨时区显示改变，绝对时间不变；
- 修改时区后重算未发送的全天提醒。

#### 6.5.2 提醒规则

- 最多 5 个提醒；
- 偏移：准时、提前 5/10/30 分钟、提前 1 小时、提前 1 天、自定义偏移（−7 天至 +1 天）；
- 不支持绝对时间提醒（MVP）；
- 全天任务默认 09:00，可在设置中调整（06:00–12:00）；
- 任务完成/删除/改期/完成重复实例后，旧提醒取消；
- 提醒身份：`reminder_spec.id` + `occurrenceKey` + `remindAt`；
- 服务端 24 小时内补发一次；超过 24 小时标记过期；
- 本地未同步提醒由客户端本地补发，上报 `localDeliveries` 去重；
- 免打扰只影响摘要/协作，不影响用户显式设置的提醒。

#### 6.5.3 时区与夏令时

- 重复任务按 `recurrence_timezone` 的本地墙钟展开；
- 全天任务/今天视图用用户当前时区；
- 春季跳变不存在的本地时间：顺延到下一个有效时间（02:30 → 03:00）；
- 秋季回拨重复的本地时间：取第一次（夏令时偏移）；
- 每轮实例重新计算，不缓存跨时区绝对提醒；
- 测试覆盖 America/New_York、Europe/Berlin、Asia/Shanghai、Australia/Lord_Howe。

#### 6.5.4 逾期

- 逾期任务保留原处并标记“已逾期”；
- 不每天重复推送；仅到期时提醒一次；
- 完成后按当前时间推进下一次重复实例；
- 逾期任务可在今天视图查看。

#### 6.5.5 验收要点

- 修改提醒时间后旧提醒不触发；
- 全天任务跨时区日期不漂移；
- DST 切换日提醒符合规则；
- 服务端故障恢复后 24 小时内补发一次；
- 本地补发与服务端提醒不重复展示。

### 6.6 FR-6 重复任务

#### 6.6.1 支持范围

| 能力 | MVP | 说明 |
| --- | --- | --- |
| 每天 | 是 | 可设间隔 |
| 每周 | 是 | 可指定星期几 |
| 每月 | 是 | 按日期；月末取最后一天 |
| 每年 | 是 | 2 月 29 日在非闰年取 2 月 28 日 |
| 间隔 | 是 | 如每 2 周 |
| 结束：永不 | 是 | |
| 结束：到日期 | 是 | 含当天 |
| 结束：执行 N 次 | 是 | N 含当前实例 |
| 单次实例例外 | P1 | MVP 仅整个系列 |
| BYSETPOS/BYWEEKNO | 否 | 不支持 |

#### 6.6.2 完成语义

- 完成当前实例：写 `lastCompletedAt`，到期时间推进到下一次，`recurrenceSeq + 1`，`completedAt` 保持空；
- 补完成较早实例：直接推进到不早于当前时间的下一次，跳过中间实例；
- 次数用尽或超过截止日期：写 `completedAt` 结束系列，任务进入已完成；
- 完成请求带 `occurrenceKey` + `completionId`；服务端 `(taskId, occurrenceKey)` 唯一，防两台设备重复完成；
- 撤销最近一次完成：5 秒内按 `completionId` 恢复旧到期、计数、序号、上次完成时间；
- 两台设备离线完成同一实例，服务端只记录一次，不重复推进。

#### 6.6.3 编辑与删除

- MVP 编辑整个系列；UI 提示“将影响当前及未来”；
- 修改规则后以当前实例日期为基准重算后续；
- 删除任务 = 删除整个系列当前行；已完成历史台账保留（P2 可查）；
- 结束系列 = 关闭重复规则或完成最后一次。

#### 6.6.4 边界

- 每月 31 日在 2 月取 28/29 日；
- 每年 2 月 29 日在非闰年取 2 月 28 日；
- DST 规则见 §6.5.3；
- 提醒随实例推进重算，旧提醒取消。

#### 6.6.5 验收要点

- 每周一 09:00 完成后下一次为下周一 09:00；
- 连续三周未完成只保留一条逾期任务；
- N 次/截止日期正确结束；
- 两台设备并发完成同一实例不重复推进；
- 修改规则不产生重复实例。

### 6.7 FR-7 备注与附件

#### 6.7.1 备注

- Markdown 子集：加粗、斜体、标题、列表、引用、链接、行内代码；
- 最长 10,000 字符；
- 渲染前做 HTML 清洗；
- 外链使用内置浏览器并显示域名；
- 自动保存（P1）；
- 空备注显示占位，不占空间。

#### 6.7.2 附件（P1）

| 项目 | 规则 |
| --- | --- |
| 类型 | JPEG、PNG、WebP、PDF |
| 单文件 | ≤20MB |
| 单任务 | ≤5 个 |
| 免费配额 | 500MB/用户 |
| 上传 | 预签名 URL 直传对象存储 |
| 缩略图 | 图片生成 200px 缩略图 |
| 离线 | 已缓存可查看；未缓存显示占位 |
| 删除 | 软删除 7 天后物理删除 |
| 安全 | 私有桶、短时效签名 URL、病毒扫描（P1） |

#### 6.7.3 验收要点

- 上传中断可重试且不产生重复附件；
- 超出配额提示明确；
- 删除任务后附件按策略清理；
- 备注 XSS 被阻断。

### 6.8 FR-8 离线与同步

#### 6.8.1 用户可见行为

| 状态 | 展示 | 触发 |
| --- | --- | --- |
| 已同步 | 云图标/“已同步” | 无待同步操作且已追平 |
| 同步中 | 旋转图标 | 正在 push/pull |
| 离线 | 断网图标 | 网络不可用 |
| N 项待同步 | 数字徽标 | outbox 非空 |
| 有冲突 | 橙色标记 | 存在冲突任务 |

#### 6.8.2 规则

- 所有 P0 写入先本地事务（业务表 + outbox），再上传；
- 同步触发：启动、回前台、写入后 500ms 防抖、网络恢复、前台每 60 秒；
- 多设备前台可见延迟 ≤60 秒；回前台/网络恢复立即同步；
- push 每批 ≤100 条；MVP 不合并同实体操作；
- ack 前不得删除 outbox；
- 冲突字段保留服务端版本，非冲突字段合并；任务标记“已合并冲突”；
- 游标过期（30 天）→ 上传 outbox → 影子表全量重建 → 原子切换；失败保留旧库；
- 失败退避：指数 + 抖动，最多 5 次后“稍后重试”，可手动触发；
- 退出登录清理本地缓存与游标，按 userId 隔离。

#### 6.8.3 验收要点

- 30% 丢包/随机断网下已 ack 操作不丢不重；
- 两设备并发编辑不同字段最终一致；
- 同字段冲突有可见提示，不静默覆盖；
- 弱网删除不复活；
- 游标过期重建期间不出现空白页。

### 6.9 FR-9 通知

#### 6.9.1 类型

| 类型 | 优先级 | 说明 |
| --- | --- | --- |
| 任务提醒 | P0 | 到点推送，点击深链 |
| 每日摘要 | P1 | 早上汇总今天任务 |
| 协作动态 | V2 | 共享清单变更 |
| 同步冲突 | P1 | 应用内提示，不推送 |

#### 6.9.2 规则

- 登录后请求通知权限；拒绝不阻塞；
- 设备 token 变化时更新；退出/移除设备时注销；
- 提醒使用稳定 `reminderId` + `occurrenceKey`；
- 正常路径同一提醒只收到一次；极端重复由客户端去重；
- 免打扰时段只影响摘要/协作；
- 点击通知：任务存在 → 详情；已删除 → 今天并提示；
- 推送失败记录错误码；明确失效 token 清理；完整 receipt P1；
- 到达率、延迟纳入监控。

#### 6.9.3 验收要点

- 修改提醒后旧通知不出现；
- 多设备 token 正确注销；
- 通知深链正确；
- 送达率与延迟达标。

### 6.10 FR-10 统计与回顾（P1）

- 本机统计：今日/本周完成数、连续完成天数、最近 30 天趋势；

#### 验收要点

- 关闭统计开关后不采集；
- 跨端差异在 P1 有明确说明。

### 6.11 FR-11 设置与数据

| 分组 | 设置项 | 存储 |

| NFR-10 | 可观测 | 关键链路追踪；告警 5 分钟内触达 |
| NFR-11 | 能耗 | 同步批量+退避；前台轮询 ≤1 次/分钟；无常驻后台 |
| NFR-12 | 包体 | iOS/Android 安装包 ≤80MB；首屏资源按需 |

### 9.2 隐私

- 不采集任务标题、备注、附件内容；

- 分析 SDK 初始化前不发送事件；
- 隐私政策列明数据用途、保留期、第三方处理者。

## 10. 验收场景（Given / When / Then）

| 编号 | 场景 | 验收标准 |
| --- | --- | --- |
| AT-01 | 离线快速记录 | Given 无网络；When 输入标题保存；Then 任务立即出现、重启仍在、恢复网络自动同步且不重复 |
| AT-02 | 今天视图 | Given 有逾期/今天/今天完成任务；When 打开今天；Then 分组正确、计数正确、完成项折叠 |
| AT-03 | 提醒 | Given 设置 09:00 提醒；When 到点；Then 收到一次；改期后旧提醒不触发 |
| AT-04 | 重复任务 | Given 每周一 09:00；When 完成；Then 下一次下周一；连续未完成只保留一条逾期 |
| AT-05 | 重复并发完成 | Given 两台设备离线完成同一实例；When 同步；Then 服务端只记录一次，不重复推进 |
| AT-06 | 多设备同步 | Given A/B 在线；When A 修改不同字段；Then B 在 60 秒内看到；同字段冲突有提示 |
| AT-07 | 删除恢复 | Given 删除任务；When 5 秒内撤销/回收站恢复；Then 任务恢复并同步到其他设备 |
| AT-08 | 游标过期 | Given 离线超过 30 天；When 同步；Then 提示重建，重建期间不空白，失败保留旧库 |
| AT-09 | 中文搜索 | Given 50,000 条任务；When 搜索 2 字/3 字；Then 200ms 内命中标题/备注 |
| AT-10 | 令牌撤销 | Given 已登录设备；When 远程移除；Then 下一次请求被拒绝，刷新令牌失效 |
| AT-11 | 注销 | Given 已登录；When 注销；Then 立即停用、30 天内删除、旧令牌不可用 |
| AT-12 | 导出 | Given 有任务/清单/标签；When 导出 JSON；Then 24 小时内可下载，结构完整 |
| AT-13 | 时区/DST | Given 跨时区/DST 日期；When 显示今天/提醒；Then 日期不漂移，提醒按规则 |
| AT-14 | 配额/限制 | Given 达到上限；When 继续添加；Then 明确提示，不产生半成品数据 |
| AT-15 | 无障碍 | Given 开启大字号/读屏；When 使用核心流程；Then 可完成且标签可读 |
